# iPad Display — нативное приложение (для кабеля USB)

Нужно только для подключения **по кабелю**. Для Wi-Fi ничего ставить на iPad не надо —
достаточно Safari (см. корневой README).

Приложение слушает TCP-порт 7801 и показывает JPEG-кадры, которые шлёт хост.
Транспорт ему безразличен: по USB хост подключается через usbmuxd (встроенный
клиент `usbmux.js`, без iproxy), по Wi-Fi — напрямую на IP iPad.

## Что нужно

- Mac с Xcode, который **умеет собирать под iOS 9 и 32-битный armv7**: Xcode 12.x или 13.x
  (macOS Big Sur / Monterey). iPad mini 1 (A1432), iPad 2/3 — процессор A5, 32-битный,
  максимум iOS 9.3.5. Xcode 14 и новее не собирают armv7 и требуют минимум iOS 11, поэтому
  не подойдут; облачные сборщики (GitHub Actions) тоже — там нет Xcode 13.
  Если Mac нет, вариант — виртуальная машина с macOS Monterey и Xcode 13.4.
- Apple ID. Бесплатного достаточно: приложение ставится через Xcode на своё устройство,
  но профиль живёт 7 дней, потом нужно переустановить (Product → Run).
- На iPad: Настройки → Основные → Профили → доверить сертификату разработчика.

## Сборка

1. Xcode → File → New → Project → iOS → App (Objective-C, Storyboard — любой вариант).
   Product Name: `IPadDisplay`, Deployment Target: **9.0**, Devices: iPad.
2. Удалите из проекта `Main.storyboard`, `SceneDelegate.*` (если создался) и `LaunchScreen`-ссылку
   в Info.plist не трогайте. В Info.plist удалите ключи `UIMainStoryboardFile`
   и `UIApplicationSceneManifest`, если они есть.
3. Замените `AppDelegate.h/.m`, `ViewController.h/.m`, `main.m`, `Info.plist` файлами из этой папки,
   добавьте `FrameServer.h/.m` в таргет.
4. Signing & Capabilities → Team: ваш Apple ID. Bundle Identifier любой уникальный.
5. Подключите iPad кабелем, выберите его как устройство и нажмите Run.

## Использование по USB

На компьютере должен работать usbmuxd: на macOS он есть в системе, на Windows его даёт
iTunes или приложение «Apple Devices» из Microsoft Store.
Отдельный `iproxy` не нужен — хост подключается к usbmuxd сам.

Откройте приложение на iPad, в панели хоста в блоке «3b» выберите режим «USB (usbmuxd)»,
нажмите «Подключить», затем «Старт». По USB нет ограничений Wi-Fi, можно поднять FPS и
качество JPEG. Проверка туннеля из командной строки: `node tools/usbmux-list.js`.

## Использование по Wi-Fi через приложение

Приложение показывает свой IP на экране ожидания. Впишите его в поле «Хост» панели.
Разницы с веб-клиентом по картинке нет, но приложение не даёт iPad уснуть и не имеет
ограничений Safari.

## Статус

Код написан под iOS 9 SDK (BSD-сокеты + GCD, без сторонних библиотек) и по протоколу
проверен эмулятором `tools/test-tcp-device.js` на стороне хоста. Само приложение на
устройстве **не собиралось и не запускалось** — на машине, где писался проект, нет Mac.
